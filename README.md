# Flora Brasileira

Projeto desenvolvido utilizando **HTML5 e CSS3**, com o objetivo de apresentar algumas das plantas nativas mais conhecidas do Brasil, destacando suas origens, características e curiosidades.

## Sobre o projeto

O Brasil possui uma das maiores biodiversidades do planeta, abrigando uma enorme variedade de espécies vegetais distribuídas por diferentes biomas.

Este projeto apresenta um pouco dessa riqueza natural por meio de uma página web informativa, com conteúdo organizado e elementos visuais.

## Plantas apresentadas

- **Pau-brasil (*Paubrasilia echinata*):** árvore símbolo da história brasileira.
- **Vitória-régia (*Victoria amazonica*):** planta aquática conhecida por suas enormes folhas circulares.
- **Ipê-amarelo (*Handroanthus albus*):** árvore famosa por suas flores amarelas.
- **Mandacaru (*Cereus jamacaru*):** cacto típico da Caatinga, adaptado ao clima semiárido.

## Tecnologias utilizadas

- HTML5 — estruturação e organização do conteúdo.
- CSS3 — estilização, cores, posicionamento e layout da página.

## Objetivos

- Praticar os fundamentos de HTML5 e CSS3.
- Desenvolver uma página web informativa.
- Conhecer algumas espécies nativas da flora brasileira.
- Valorizar a biodiversidade e a preservação ambiental.
